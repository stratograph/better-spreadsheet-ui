First-time setup
  1. In Google Cloud Console, create a project (or use an existing one) and enable the Google Sheets API.
  2. Configure the OAuth consent screen (External, your own email as test user is fine).
  3. Create an OAuth Client ID of type Web application.
  4. Add this page's origin as an Authorized JavaScript origin:
